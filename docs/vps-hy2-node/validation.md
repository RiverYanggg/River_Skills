# vps-hy2-node 验证记录

## 本次流程覆盖

- RackNerd 个人 KVM VPS：2 vCPU、2 GB RAM、35 GB SSD、1 Gbps 公网端口和 5000 GB 月度流量。
- Ubuntu VPS 环境检查、SSH 保留、Hysteria 2 服务、TLS 证书、密码认证、systemd 开机自启。
- 生成并导入 Mihomo/Clash Meta YAML；同时整理 Android FlClash/Karing 的导入说明。
- 服务端日志、监听端口、客户端真实 HTTPS 请求和出口 IP 验证。
- 桌面和浏览器在节点部署中不是必需依赖，后续已关闭以节省资源。

## 真实网络结果

同一 VPS/IP 和节点配置的对照结果：

- Wi-Fi：可用。
- 中国移动：不可用。
- 中国电信：可用。
- 中国联通：可用。

移动/Wi-Fi 结果来自会话中的测试，电信、联通可用按用户最终提供的运营商结论记录；并非本次仓库整理重新独立测试。

这里仅保留运营商结论，不记录手机热点排障过程。结论表示该 VPS/IP 当前到不同运营商的线路差异，不保证其他地区、IP 或时间段完全相同。

## 验证边界

仓库中的 Skill、参考文档和链接检查可在本地复现；真实 VPS 部署和客户端联网结果来自上述实际环境。示例 YAML 使用占位符，不能直接导入生产客户端；实际配置必须由 Agent 根据用户提供的服务端认证信息生成，并禁止将密码和私钥提交到 Git。

本次整理没有再次部署服务器或操作手机 App。Karing 的完整字段转换、不同版本导入后的设置保留需要在目标 App 核验，不声称所有版本均已测通。本次尝试重新读取 Hysteria 官网时遇到 DNS 解析失败，保留官方链接供使用技能时读取当前版本说明。仓库结构与本地文档链接检查已通过。
